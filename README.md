# Responsive-Header-with-Hamburger-Menu
A modern, responsive navigation header built with HTML5, CSS3, and JavaScript. This project features a clean UI, an animated hamburger menu created using three &lt;span> bar elements, a sticky navigation bar, smooth transitions, and a fully responsive layout for desktop, tablet, and mobile devices.

🍔 Hamburger Menu

The mobile menu icon is created using three <span> elements, making it lightweight and easy to animate.

<div class="hamburger">
    <span class="bar"></span>
    <span class="bar"></span>
    <span class="bar"></span>
</div>

Typical animations include:

☰ Hamburger → ✕ Close icon
Slide-in mobile navigation
Smooth CSS transitions

Move into the project folder:

cd responsive-header

Open index.html in your browser or use the VS Code Live Server extension.
